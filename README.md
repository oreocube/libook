# LiBook - 도서관 도서 검색 앱
<img width="1040" height="552" src="https://github.com/user-attachments/assets/80522fb9-3c50-421b-9e53-da42a56492e8" />

## Features
- 대출 급상승 도서
- 지역별 도서관 조회
- 관심 도서관 조회/등록/삭제
- 도서 검색
- 도서관 별 도서 소장 여부 조회 및 알림 설정

## Made with
- Jetpack Compose
- Firebase Firestore
- 도서관 정보나루 Open API (https://www.data4library.kr/)
